# Spring Boot Tomcat Demo

A lightweight Spring Boot application created for DevOps and CI/CD practice.

## Application Details

- **Application Name:** springboot-tomcat-demo
- **Java Version:** 21
- **Maven Version:** 3.9.12
- **Spring Boot Version:** 3.5.4
- **Application Server:** Apache Tomcat 11
- **Build Tool:** Maven
- **Deployment Type:** WAR
- **CI/CD:** Jenkins (planned)
